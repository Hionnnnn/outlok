🔧 Setup Wizard — 5 Menit Sekali Saja

Belum selesai
ⓘ
Microsoft mewajibkan setiap aplikasi punya Client ID sendiri (gratis). Ini satu-satunya cara agar app bisa akses email tanpa backend. Setelah selesai sekali, semua akun bisa di-connect.

1 Buka Azure Portal

Klik link di bawah, login pakai akun Microsoft Anda (bisa akun Outlook/Hotmail pribadi).

🔗 Buka Azure App Registrations

2 Daftarkan Aplikasi Baru

Klik + New registration, isi:

• Name: Outlook Bulk Manager
• Supported account types: Personal Microsoft accounts only (untuk outlook/hotmail) atau Accounts in any org directory and personal (kalau perlu akun kerja juga)
• Redirect URI: pilih Single-page application (SPA), isi dengan URL di bawah

...

Redirect URI ini otomatis menunjuk ke halaman ini. Harus HTTPS atau http://localhost.

3 Salin Application (Client) ID

Setelah registrasi selesai, di halaman Overview akan terlihat Application (client) ID. Salin dan tempel di bawah:

4 Tambahkan API Permissions

Di menu kiri app Anda → API permissions → Add a permission → Microsoft Graph → Delegated permissions. Tambahkan:

• User.Read (default)
• Mail.Read
• Mail.Send ← wajib untuk forward
• offline_access ← untuk refresh token
• openid, profile, email

Terakhir klik Grant admin consent jika tersedia (opsional untuk akun personal).

5 Simpan & Uji Koneksi

⚠
Jika muncul error "CORS" atau "AADSTS" saat connect:
Pastikan Redirect URI sudah terdaftar sebagai Single-page application (bukan Web) di Azure. Setelah mengubah platform, tunggu 1–2 menit.
